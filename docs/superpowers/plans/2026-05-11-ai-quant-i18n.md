# AI Quant I18n Coverage Implementation Plan

**Goal:** Ensure AI Quant user-facing UI supports both Chinese and English through the existing `common.json` locale resources.
**Track:** B
**Total PRs:** 1
**Issue:** #1228

## Scope

- Cover AI Quant account list, strategy detail, strategy stop/delete dialogs, running-strategy edit guard, plaza/backtest/report surfaces where user-visible strings are currently hard-coded.
- Keep user-generated strategy content, parser keywords, test fixtures, and backend/API error fallback strings in their original language unless they are directly rendered as fixed UI labels.
- Use the existing `apps/front/public/locales/{zh,en}/common.json` resources and `react-i18next` patterns.

## Tasks

### Task 1: Fill Locale Keys

**Files:**
- Modify `apps/front/public/locales/en/common.json`
- Modify `apps/front/public/locales/zh/common.json`

**Steps:**
1. Add missing AI Quant action keys such as stop strategy and delete.
2. Add grouped keys for runtime control, strategy detail labels, stop dialog, delete dialog, guard dialog, and account strategy diagnostics.
3. Keep key names under `aiQuant` to match the existing namespace.

**Verify:**
- JSON parses successfully.
- Existing keys remain backward compatible.

### Task 2: Replace Hard-Coded UI Strings

**Files:**
- Modify `apps/front/src/components/account/AiQuantStrategyList.tsx`
- Modify `apps/front/src/components/account/AiQuantStrategyDetail.tsx`
- Modify `apps/front/src/components/ai-quant/StopRunningStrategyDialog.tsx`
- Modify `apps/front/src/components/ai-quant/AiQuantDeletionDialog.tsx`
- Modify `apps/front/src/components/ai-quant/RunningStrategyEditGuardDialog.tsx`
- Modify other AI Quant route/component files only when they contain fixed user-visible UI strings in the same surface.

**Steps:**
1. Use `useTranslation()` in React components that do not already have it.
2. Pass `lng` or a translation function into helper functions when they generate fixed UI labels.
3. Avoid translating dynamic strategy names, AI/user messages, and backend-provided descriptions.

**Verify:**
- English UI no longer shows fixed Chinese labels in the affected AI Quant pages/dialogs.
- Chinese UI keeps the intended Chinese wording.

### Task 3: Update Focused Tests

**Files:**
- Modify related front-end unit tests only where assertions depend on changed fixed labels.

**Steps:**
1. Update mocked translations to include newly required keys.
2. Keep behavior assertions intact.

**Verify:**
- Run focused front-end unit tests for account AI Quant list/detail and i18n.
- Run `dx build front --dev` if time allows after focused tests.

## Delivery
