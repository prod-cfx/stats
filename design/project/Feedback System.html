05

使用规范 · Spec

when to use which
层级 · 阻塞性 (从低到高)
Toast 不阻塞 · 自动消失 · 单条信息
Banner 不阻塞 · 持续显示 · 与上下文关联
Empty 占位整个内容区 · 替代列表
Dialog 阻塞 · 需用户决策才能继续
语义色映射
success 操作成功、已保存、已部署
warn 风险提示、降级、即将到期
danger 失败、错误、不可逆操作
info 中性通知、提示、系统消息
accent 进行中 / Loading / 操作主色
跨平台尺寸
Toast PC 宽 280–460 · Mobile 宽 calc(100% - 24px)
Banner 跟随容器宽度 · padding 12 / 14
Empty 插画 PC 144 · Mobile 120
Dialog PC 460 · Mobile (100% - 32)
圆角 卡片 14 · pill 999 · banner 12
行为规则
Error 不自动消失 · 必须有「重试」或「关闭」
同类去重 同 key 的 toast 同时只显示一条 · 计数 ×N
堆叠上限 同时最多 3 条 toast · 超过排队
Dialog Esc / 遮罩点击 = 取消 · 危险操作不允许遮罩关闭
Empty CTA 至多 2 个按钮 · 主操作使用 btn-primary
