# quantify-mobile 国际化（i18n）维护

## 概述

本项目使用 Flutter 官方 `flutter_localizations` + `gen_l10n` 工具链：

- 资源文件：`lib/l10n/app_zh.arb`（默认 template，简体中文）、`app_en.arb`（英文占位）
- 配置：`l10n.yaml`
- 生成产物：`lib/l10n/app_localizations.dart` + `app_localizations_zh.dart` + `app_localizations_en.dart`（**必须 commit 入库**，PR 间依赖）

## 添加 / 修改词条

1. 编辑 `lib/l10n/app_zh.arb`：

   ```json
   {
     "@@locale": "zh",
     "me_settings_logout": "退出登录",
     "@me_settings_logout": { "description": "我的页面 - 退出登录按钮" }
   }
   ```

2. 同步编辑 `lib/l10n/app_en.arb`（key 必须一一对齐，无翻译时可暂留同 zh 字符串）：

   ```json
   {
     "@@locale": "en",
     "me_settings_logout": "Sign out"
   }
   ```

3. 跑 `flutter pub get`，自动触发 `gen_l10n` 重新生成 `lib/l10n/app_localizations*.dart`。

4. 在业务代码引用（注意：`l10n.yaml` 中 `nullable-getter: false`，`of()` 返回非空，**不要加 `!`**）：

   ```dart
   import '../../l10n/app_localizations.dart';
   // ...
   Text(AppLocalizations.of(context).me_settings_logout);
   ```

5. `git add lib/l10n/app_localizations*.dart` 把 generated 文件提交（关键，否则其他人 pull 后报缺失）。

## 词条命名约定

- 格式：`<page>_<section>_<key>`，小写下划线，例如 `me_settings_logout`、`market_detail_tab_kline`
- 通用词条用 `common_` 前缀：`common_confirm`、`common_cancel`
- 错误文案 `error_<scope>_<key>`：`error_auth_invalid_credential`

## 边界规则

| 路径 | 是否替换中文 |
|------|------------|
| `lib/pages/`、`lib/shell/`、`lib/widgets/`、`lib/router/`、`lib/main.dart` | 必须替换为 `AppLocalizations.of(context)!.xxx` |
| `lib/data/mock/**`、`lib/data/models/**` | **保留**（属于数据 fixture / 领域模型，不是 UI 文案） |
| 行内注释 `// 中文说明` | **保留**（注释不是字面量） |

## 硬验收命令

```bash
cd apps/quantify-mobile
# 已知漏网：Dart 三引号字符串（"""..."""、'''...'''）跨行场景不在此 grep 检测范围；
# 现阶段 UI 文案均为单行 Text(...) 字面量，三引号若引入需人工 review。
if grep -rnP '"[^"]*[\x{4e00}-\x{9fff}][^"]*"|'"'"'[^'"'"']*[\x{4e00}-\x{9fff}][^'"'"']*'"'"'' \
     lib --include='*.dart' \
   | grep -v 'lib/data/mock' \
   | grep -v 'lib/data/models' \
   | grep -vE '^[^:]+:[0-9]+:\s*//' ; then
  echo "FAIL: 仍有硬编码中文字面量"; exit 1
fi
echo "PASS"
```

## 添加新 locale

1. 复制 `app_zh.arb` → `app_<locale>.arb`，改 `@@locale` 与所有 value
2. `flutter pub get` 触发再生成
3. 如需在 main.dart 切默认 locale，修改 `locale: const Locale('<locale>')`

## 注意事项

- `intl` 由 Flutter SDK 通过 `flutter_localizations` pin 至 0.20.2；`k_chart_plus` 1.0.4 老约束 `^0.19.0`，故在 pubspec.yaml `dependency_overrides` 中显式强制 `intl: 0.20.2` 对齐 SDK 版本，避免冲突
- `synthetic-package` 在 Flutter 3.22+ 已废弃，本项目 `l10n.yaml` 不声明该字段，generated 文件直接落 `lib/l10n/`
- 不要手改 `lib/l10n/app_localizations*.dart`（generated 产物），改 arb 后重跑 `flutter pub get`
